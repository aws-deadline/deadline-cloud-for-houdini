# AWS Deadline Cloud for Houdini User Guide

This guide provides step-by-step instructions for using AWS Deadline Cloud with Houdini to render your projects faster by distributing rendering tasks across multiple machines.

## What's Inside

This user guide covers:

* [Installation](installation.md) - How to install the Houdini submitter
* [Using the submitter](submitter/index.md) - How to prepare and submit rendering jobs
* [Husk rendering and USD workflows](submitter/husk-rendering.md) - How to render exported USD scenes using Husk with AWS Deadline Cloud
* [Telemetry](telemetry.md) - How this repository uses telemetry and how to opt out
* [Frequently asked questions](FAQ.md)
